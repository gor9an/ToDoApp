
# ToDoApp - приложение для управления задачами

## Основные возможности

- **Создание задач**: Добавление задач с детальными описаниями и дедлайнами
- **Категории и метки**: Гибкая система организации через категории и теги
- **Система приоритетов**: Трехуровневая маркировка важности задач
- **Тема оформления**: Поддержка темной/светлой темы системы

## Технологии
### Используемый стек
- **Swift**: Основной язык разработки
- **SwiftUI**: Фреймворк для декларативного UI
- **UIKit**: Для сложных кастомных компонентов
- **SwiftData**: Персистентное хранилище данных
- **MVVM**: Архитектура приложения
- **FileCache**: Система кэширования файлов импортируется из https://github.com/gor9an/TodoItemsFileCache
